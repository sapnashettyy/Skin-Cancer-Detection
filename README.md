# Skin Cancer Detection Using Deep Learning

## Overview

This project explores skin cancer detection using a Convolutional Neural Network (CNN) trained on skin lesion images.

## Project Contents

- `SkinCaner.ipynb` — Jupyter notebook containing the model development and experiments.
- `model_accuracy_v2.png` — model accuracy plot.
- `model_loss_v2.png` — model loss plot.
- `requirements.txt` — Python dependencies.
- `.gitignore` — files excluded from Git.

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Setup

1. Clone or download this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Open `SkinCaner.ipynb` in Jupyter Notebook or VS Code.

## Dataset and Model

The dataset and trained model are not included in this repository. Configure the notebook with the appropriate local dataset and model paths before running the relevant cells.

## Disclaimer

This project is for educational and research purposes only. It is not a substitute for professional medical evaluation or diagnosis.
